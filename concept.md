# Концепция редизайна zvs.by (прототип, пакет Б)

## Палитра (только цвета логотипа + нейтральные)
Цвета логотипа извлечены PIL из logo-1-1.png (1304×745):
- `#009CFF` — основной синий логотипа (кнопки, акценты)
- `#48BDFF` — средний голубой логотипа (ховеры, номера шагов, рамки)
- `#7ADCFF` — светлый голубой логотипа (обводки на тёмном)
- Оттенки/тона основного: `#0074C2` (тёмный, ссылки, ховер кнопки), `#00457A` (глубокий, начало градиента hero), `#E6F5FF` и `#F3FAFF` (светлые фоны секций и меток)
- Нейтральные: `#FFFFFF`, `#EEF2F5`, `#C9D2DB`, `#6B7785`, `#3D4A56`, `#0F1B26` (почти чёрный — текст, форма, подвал)

## Шрифт
Golos Text (Google Fonts, кириллица, 400–800) — тот же, что у agrodroncentr.ru; запасные system-ui/Arial. Заголовки 700–800 с отрицательным трекингом, текст 16 px.

## Что взяли из референсов (паттерны, без их бренда/текстов/картинок)
**agrodroncentr.ru**: H1 «что + кому + выгода» в hero, две кнопки (основная заявка + каталог), телефон прямо в hero; метки-«надзаголовки» над H2 (у них [ в скобках ]); блок «Как купить» шагами; повтор CTA-формы внизу; крупные скруглённые кнопки-пилюли; Golos Text.
**natura-lab.ru**: модульная сетка карточек «система из N модулей» → у нас 4 вида животных и 9 групп каталога; спокойные светлые секции с чередованием фона; шаги «от … до …» с крупной нумерацией 01/02/03; много воздуха, крупный кегль, минимум декора.

## Структура страниц
- **Главная (index.html)**: hero (H1, 2 CTA, tel) → виды животных → 9 групп → популярные препараты (карточки с «Запросить цену») → О компании + 4 преимущества (тексты с сайта) → документы [заглушки] → как заказать → форма заявки → подвал с реквизитами.
- **Каталог (catalog.html)**: крошки, H1, фильтр «Вид животного» и «Группа» (чипсы), сетка 2 кол. на мобилке / 3 на десктопе.
- **Товар (product.html, МастиБак)**: фото [заглушка], H1 = название, ключевые параметры таблицей, CTA + PDF-инструкция, вкладки Состав/Показания/Дозы/Противопоказания, похожие препараты.
- **Контакты (contacts.html)**: отделы РБ/РФ раздельно, все tel:/mailto: кликабельны и совпадают с текстом, адрес, реквизиты, карта [заглушка].
- Везде: один уникальный H1, title/description под страницу, липкая мобильная панель «Позвонить / Запросить цену».

## Соответствие Elementor / ACF / WooCommerce
| Блок прототипа | Реализация |
|---|---|
| Шапка, подвал, липкая панель CTA | Elementor Pro Theme Builder (Header/Footer), Global Colors/Fonts из палитры |
| Hero, О компании, Как заказать, Документы | Elementor-секции; документы — ACF Repeater (файл, название) на странице опций |
| Виды животных | Ссылки на фильтр по атрибуту `pa_vid-zhivotnogo` (уже есть в BeRocket) |
| 9 групп | Loop Grid по `product_cat` |
| Популярные препараты | Loop Grid товаров с меткой/флажком ACF `is_popular` |
| Карточка товара | Elementor Single Product + ACF: `composition` (Repeater вещество/доза), `indications`, `dosage`, `contraindications`, `withdrawal_milk`, `withdrawal_meat`, `package`, `instruction_pdf`, `animals` |
| Каталог с фильтрами | Woo archive template + BeRocket AJAX Filters (атрибут вида животного, категории); цены скрыты, корзина отключена |
| «Запросить цену» | Elementor Pro Form (popup/якорь) со скрытым полем «Препарат», подставляется из названия товара; отправка на e-mail/CRM; чекбокс согласия + политика |
| Контакты | Elementor + ACF Options (телефоны, e-mail один раз — выводятся везде одинаково) |
