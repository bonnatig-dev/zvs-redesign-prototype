# ЗападВетСервис (zvs.by) — прототип редизайна, v2

Статический прототип (4 страницы: index, catalog, product, contacts). v2 — переработка в стилистике agrodroncentr.ru (полноэкранное фото в hero, «пилюльная» навигация, bento-карточки, бегущая строка, этапы, форма на фото) при сохранении логотипа и палитры zvs.by.
Тексты, препараты, реквизиты и контакты — с zvs.by; отсутствующие данные помечены «уточнить». Форма — только демо, никуда не отправляется.
