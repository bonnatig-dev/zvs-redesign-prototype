# Прототип редизайна zvs.by (ЗападВетСервис)

Это **кликабельный HTML-прототип** редизайна сайта zvs.by, а не рабочий сайт. Формы ничего не отправляют, часть блоков — заглушки в [квадратных скобках] под контент клиента. Итоговый сайт планируется на WordPress + Elementor + ACF + WooCommerce.

## Страницы
- `index.html` — главная (первый экран с фото на всю ширину)
- `catalog.html` — каталог с фильтрами по группе и виду животного
- `product.html` — карточка товара (МастиБак)
- `contacts.html` — контакты

## Фото
Все фото взяты с текущего сайта zvs.by (упаковки препаратов), список URL — `assets/img/SOURCES.md`.
Фон первого экрана — текущий фон главной zvs.by; по имени файла это фото Unsplash, а не съёмка производства ЗВС. Для реального сайта нужна фотосъёмка цеха/склада.

## Публикация
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root. Все пути относительные.
